1. Eliminación del Chattering Bang-Bang en Giro In-Situ

Problema Detectado en logs: Cuando el frente está completamente restringido, el fallback realizaba out.rotSpeed = (bearingToGoal >= 0.0) ? maxRot : -maxRot. Con ruido sensorial de milímetros, el signo oscilaba alternando +1.0 y -1.0 rad/s cada 16 ms provocando vibración severa en el chasis.
Solución: Banda muerta de alineación (< 0.05 rad), control proporcional suave y bloqueo por histéresis direccional en lastPivotRot_.

controller.cpp // In-Situ Pivot Fallback Optimización #1
357- const double bearingToGoal = std::atan2(-targetPersonX, targetPersonY);
358- out.rotSpeed = (bearingToGoal >= 0.0) ? params_.maxRotSpeed : -params_.maxRotSpeed;
357+ const double bearingToGoal = std::atan2(-targetPersonX, targetPersonY);
358+ if (std::abs(bearingToGoal) < 0.05) {
359+ out.rotSpeed = 0.0f; lastPivotRot_ = 0.0f;
360+ } else {
361+ float desiredRot = std::clamp(static_cast(bearingToGoal * params_.kpRot),
362+ -params_.maxRotSpeed, params_.maxRotSpeed);
363+ if (lastPivotRot_ != 0.0f && (desiredRot * lastPivotRot_ < 0.0f) && std::abs(bearingToGoal) < 0.25)
364+ desiredRot = (lastPivotRot_ > 0.0f) ? std::min(desiredRot, lastPivotRot_) : std::max(desiredRot, lastPivotRot_);
365+ out.rotSpeed = desiredRot; lastPivotRot_ = desiredRot;
366+ }

2. Atenuación de Velocidad en Zona de Standoff (1 Metro)

Problema Detectado: El término de recompensa de velocidad (costSpeed = 1 - adv/maxAdv) con peso 1.2 inducía al robot a mantener avances de 500-1000 mm/s incluso estando a 980-1050 mm de la persona, provocando overshoot y oscilación longitudinal.
Solución: Modulación dinámica del peso weightSpeedEff. Si el error respecto a 1000 mm es inferior a 120 mm y el pasillo está despejado, el peso se reduce de 1.2 a 0.35 para favorecer estabilidad y suavidad.

controller.cpp // Standoff Speed Weighting Optimización #2
276- const float costSpeed = 1.0f - (cand.adv / params_.maxAdvSpeed);
320- cand.cost = ... + params_.weightSpeed * costSpeed + ...;
276+ const float costSpeed = 1.0f - (cand.adv / params_.maxAdvSpeed);
277+ const float weightSpeedEff = (std::abs(distError) < 120.0f && !forwardBlocked)
278+ ? 0.35f : params_.weightSpeed;
322+ cand.cost = ... + weightSpeedEff * costSpeed + ...;
3. Discretización de Rejilla a 50 mm/s:
Se amplió advSamples = 21 (anteriormente 19), lo que garantiza que los múltiplos de velocidad lineal son exactamente enteros ($0, 50, 100, 150 \dots 1000\text{ mm/s}$), eliminando artefactos de redondeo en la integración del modelo cinemático.
